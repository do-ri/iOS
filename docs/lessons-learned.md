# Lessons Learned

이 문서는 구현 세부를 복붙하지 않고, 다시 뒤집지 않을 결정만 남긴다.

## Authentication

- 토큰 만료 판단은 클라이언트 시계보다 서버 응답을 신뢰한다.
- Splash는 인증 진입 판단을 담당하고, refresh 자체를 선행하지 않는다.
- refresh는 중복 실행되지 않도록 중앙에서 조정한다.

## Network

- refresh 요청은 일반 요청 파이프라인과 분리한다.
- 인증 실패 처리와 강제 로그아웃은 공통 네트워크 경계에서 다룬다.

## Navigation

- stack 기반 화면 전환은 "완료 후 상태"가 아니라 "전환 시점"을 기준으로 해석해야 한다.

## Rule

여기에 남기는 내용은 "다시 토론하지 않을 결정"이어야 한다.
